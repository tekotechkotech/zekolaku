# Zekolaku

Website project for a school profile, built to be simple, fast, clear, and easy to maintain.

## Goal

Provide a professional school website that communicates the school's identity, programs, facilities, news, gallery, and contact information clearly across desktop and mobile.

## Main Areas

- School profile
- Educational programs
- Facilities
- News
- Gallery
- Contact
