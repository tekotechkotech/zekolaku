# PRD 1 — Company Profile
## Phase 3: Content & Conversion Pages

### Goal
Melengkapi website dengan konten dinamis secara konsep, namun masih menggunakan static data.

### Pages

#### Kegiatan
- Daftar kegiatan sekolah
- Ekstrakurikuler
- Event
- Dokumentasi
- Detail kegiatan opsional

#### Berita
- Daftar berita
- Card berita
- Tanggal
- Kategori
- Ringkasan
- Halaman detail berita

Suggested routes:
- `/berita`
- `/berita/[slug]`

#### PPDB
- Informasi PPDB
- Jadwal
- Persyaratan
- Tahapan pendaftaran
- Biaya jika memang ditampilkan
- FAQ
- CTA daftar
- Link WhatsApp / external registration

#### Kontak
- Alamat
- Nomor WhatsApp
- Email
- Jam operasional
- Sosial media
- Embed Maps atau link Maps
- Form kontak visual tanpa backend

### Content Requirements
- Semua konten masih static
- Struktur data harus mudah dipindahkan ke database pada PRD CMS
- Gunakan slug untuk berita/kegiatan bila ada detail page

### Acceptance Criteria
- Semua halaman company profile utama selesai
- User dapat memahami sekolah tanpa login
- Jalur CTA menuju PPDB/kontak jelas
- Static content sudah terstruktur sehingga mudah dimigrasikan ke CMS
