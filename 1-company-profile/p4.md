# PRD 1 — Company Profile
## Phase 4: Polish & Production Readiness

### Goal
Menyempurnakan company profile agar siap deploy sebagai website publik.

### Scope

#### SEO
- Title per page
- Meta description
- Open Graph metadata
- Canonical URL
- Sitemap
- robots.txt
- Semantic heading structure

#### Performance
- Optimasi image
- Lazy loading
- Hindari dependency berat
- Minimalkan client-side JavaScript bila tidak diperlukan

#### Accessibility
- Alt text
- Label form
- Keyboard navigation
- Fokus yang jelas
- Kontras cukup
- Semantic HTML

#### UX Polish
- 404 page
- Loading state jika diperlukan
- Empty state bila relevan
- Hover/focus state
- Responsive refinement

#### Deployment
- Environment config minimal
- Build production sukses
- README deployment
- Tidak ada secret di repository

### Acceptance Criteria
- Lighthouse/quality audit masuk akal
- Build production sukses
- Tidak ada route rusak
- Metadata tiap halaman benar
- Website siap dipakai sebagai company profile sekolah tanpa CMS
