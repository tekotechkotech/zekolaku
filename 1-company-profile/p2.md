# PRD 1 — Company Profile
## Phase 2: Core Pages

### Goal
Membangun halaman inti yang menjelaskan identitas, kualitas, dan penawaran utama sekolah.

### Pages

#### Home
Isi minimal:
- Hero section
- Nama sekolah
- Tagline
- CTA utama
- Ringkasan sekolah
- Keunggulan utama
- Statistik singkat
- Program unggulan
- Prestasi pilihan
- Fasilitas pilihan
- Kegiatan terbaru
- CTA PPDB

#### Tentang
Isi minimal:
- Profil sekolah
- Sejarah
- Visi
- Misi
- Sambutan kepala sekolah
- Akreditasi
- Nilai / karakter sekolah

#### Program
Isi minimal:
- Daftar program/jurusan
- Nama program
- Deskripsi
- Kompetensi utama
- Prospek
- Fasilitas pendukung

#### Fasilitas
Isi minimal:
- Daftar fasilitas
- Foto
- Nama
- Deskripsi singkat

#### Prestasi
Isi minimal:
- Prestasi siswa
- Prestasi guru
- Akademik
- Non-akademik
- Tahun
- Tingkat pencapaian

### Data
Gunakan static data lokal terlebih dahulu melalui file TypeScript/JSON.

### UX Requirements
- Informasi mudah dipindai
- Card reusable seperlunya
- CTA jelas
- Foto memakai aspect ratio konsisten
- Hindari layout yang terlalu kompleks

### Out of Scope
- CRUD
- Admin
- Database
- Upload media

### Acceptance Criteria
- Semua halaman inti selesai
- Konten dummy realistis
- Tidak ada placeholder lorem ipsum
- Komponen dapat digunakan ulang
- Layout tetap ringan dan mudah dipahami
