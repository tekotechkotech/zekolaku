# PRD 1 — Company Profile
## Phase 1: Foundation

### Goal
Membangun fondasi website company profile sekolah dengan SvelteKit yang ringan, responsif, mudah dikembangkan, dan siap dipakai untuk phase berikutnya.

### Scope
- Inisialisasi project SvelteKit
- TypeScript
- Tailwind CSS
- Struktur layout utama
- Header / navbar
- Footer
- Responsive navigation
- Global typography
- Reusable UI primitives sederhana
- Routing dasar
- SEO metadata dasar
- Static asset structure

### Main Routes
- `/`
- `/tentang`
- `/program`
- `/fasilitas`
- `/prestasi`
- `/kegiatan`
- `/berita`
- `/ppdb`
- `/kontak`

### UI Requirements
- Mobile-first
- Bersih, modern, profesional
- Cocok untuk sekolah SD/SMP/SMA/SMK
- Tidak terlalu ramai
- CTA utama mudah terlihat
- Komponen reusable tetapi tidak over-engineered

### Suggested Structure
```text
src/
├── lib/
│   ├── components/
│   └── data/
├── routes/
└── app.html
```

### Out of Scope
- Database
- Authentication
- CMS
- Dashboard admin
- Multi-tenant
- Payment
- Sistem akademik

### Acceptance Criteria
- Project dapat dijalankan tanpa error
- Semua route utama tersedia
- Header dan footer konsisten
- Responsive di mobile, tablet, desktop
- Tidak ada horizontal overflow
- Struktur kode cukup sederhana untuk dilanjutkan agent berikutnya
