# PRD 2 — CMS
## Phase 4: PPDB, Contact & Site Settings

### Goal
Mengelola informasi konversi dan konfigurasi website tanpa edit kode.

### Modules

#### PPDB
Editable:
- title
- description
- opening_date
- closing_date
- requirements
- registration_steps
- fee_information
- registration_url
- whatsapp_number
- faq

#### Contact
Editable:
- address
- phone
- whatsapp
- email
- map_embed_url
- operational_hours

#### Social Media
- Instagram
- Facebook
- TikTok
- YouTube

#### General Settings
- School logo
- Favicon
- Website title
- Default SEO description
- Footer text

### Acceptance Criteria
- Informasi PPDB dapat diubah dari admin
- Kontak dan sosial media dapat diubah tanpa edit source code
- Branding dasar dapat diatur melalui CMS
