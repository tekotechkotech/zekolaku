# PRD 2 — CMS
## Phase 5: CMS Hardening

### Goal
Membuat CMS cukup aman, nyaman, dan stabil untuk dipakai sekolah.

### Scope

#### Authorization
- Minimal role: admin
- Optional editor jika memang dibutuhkan
- Protect semua mutation

#### Security
- CSRF protection sesuai framework
- Secure session
- Rate limiting login bila tersedia
- Server-side validation
- Safe file upload
- Tidak expose secret

#### Auditability
Minimal:
- created_at
- updated_at
- created_by bila relevan
- updated_by bila relevan

#### Dashboard
Ringkasan:
- Jumlah berita
- Jumlah kegiatan
- Jumlah prestasi
- Draft vs published

#### Content Quality
- Slug uniqueness
- Required SEO fields
- Preview sederhana jika efisien

#### Backup
- Dokumentasi backup database
- Dokumentasi backup uploads

### Acceptance Criteria
- CMS stabil untuk penggunaan harian
- Semua input tervalidasi server-side
- Unauthorized access ditolak
- Backup procedure terdokumentasi
- Tidak ada fitur SaaS/multi-tenant pada tahap ini
