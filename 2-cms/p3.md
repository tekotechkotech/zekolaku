# PRD 2 — CMS
## Phase 3: Media, Activities & News

### Goal
Menyediakan pengelolaan konten editorial dan media.

### Modules

#### Media
- Upload image
- Validasi mime type
- Validasi size
- Penyimpanan local filesystem untuk phase ini
- Generate filename aman
- Delete media yang tidak dipakai bila aman

#### Activities
CRUD:
- title
- slug
- summary
- content
- event_date
- cover_image
- status

#### News
CRUD:
- title
- slug
- excerpt
- content
- cover_image
- published_at
- status
- category optional

### Public Pages
- Listing
- Detail by slug
- Published only
- Draft tidak tampil ke publik

### Security
- Validasi file upload
- Sanitasi / safe rendering untuk rich content
- Admin-only mutation

### Acceptance Criteria
- Admin dapat upload dan memakai gambar
- Berita dan kegiatan dapat publish/unpublish
- Public detail page berdasarkan slug
- Draft tidak bocor ke public
