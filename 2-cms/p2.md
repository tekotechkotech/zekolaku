# PRD 2 — CMS
## Phase 2: Core Content Management

### Goal
Admin dapat mengelola konten utama company profile.

### Modules

#### School Profile
- Nama sekolah
- Tagline
- Deskripsi
- Sejarah
- Visi
- Misi
- Sambutan kepala sekolah
- Akreditasi

#### Programs
CRUD:
- name
- slug
- description
- competencies
- prospects
- status
- sort_order

#### Facilities
CRUD:
- name
- slug
- description
- image
- sort_order
- status

#### Achievements
CRUD:
- title
- description
- category
- level
- achieved_at
- image
- status

### Validation
Gunakan Zod untuk semua form.

### UX Admin
- Table/list
- Create
- Edit
- Delete dengan konfirmasi
- Flash message
- Error message per field
- Pagination bila diperlukan

### Acceptance Criteria
- Admin dapat mengelola semua modul di atas
- Public website membaca data dari database
- Tidak ada hardcoded content utama yang seharusnya editable
