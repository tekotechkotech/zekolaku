# PRD 2 — CMS
## Phase 1: CMS Foundation

### Goal
Mengubah website static menjadi website yang kontennya tersimpan di database dan dapat dikelola admin.

### Tech Direction
- SvelteKit
- TypeScript
- MariaDB
- Drizzle ORM
- Zod validation
- Authentication library yang ringan dan matang

### Core Entities
Minimal:
- users
- school_profile
- programs
- facilities
- achievements
- activities
- news
- ppdb
- contact_settings

### Scope
- Setup MariaDB connection
- Setup Drizzle
- Migration
- Seed
- Authentication admin
- Protected admin routes
- Dashboard shell
- Zod validation dasar

### Suggested Admin Routes
```text
/admin
/admin/login
/admin/profile
/admin/programs
/admin/facilities
/admin/achievements
/admin/activities
/admin/news
/admin/ppdb
/admin/settings
```

### Rules
- Public website tetap dapat diakses tanpa login
- Admin route wajib protected
- Jangan implementasi multi-tenancy
- Jangan implementasi roles kompleks dulu

### Acceptance Criteria
- Admin dapat login/logout
- Database dan migration bekerja
- Admin dashboard dapat diakses setelah login
- Static data mulai siap digantikan data database
