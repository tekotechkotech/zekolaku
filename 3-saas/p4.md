# PRD 3 — SaaS
## Phase 4: Website Customization

### Goal
Setiap sekolah dapat menyesuaikan website tanpa mengubah kode.

### Features

#### Branding
- Logo
- Favicon
- Primary branding preference
- School identity

#### Homepage
- Reorder section
- Show/hide section
- Select featured programs
- Select featured achievements
- Select latest news count

#### Navigation
- Enable/disable menu
- Custom label sederhana

#### Theme
- Beberapa preset theme
- Hindari page builder bebas pada phase ini

### Principle
Gunakan konfigurasi terbatas dan terstruktur agar sistem tetap maintainable.

### Acceptance Criteria
- Setiap tenant dapat memiliki tampilan berbeda
- Customization tidak menyebabkan layout rusak
- Konfigurasi tersimpan per school
