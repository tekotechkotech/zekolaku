# PRD 3 — SaaS
## Phase 2: Identity & Access

### Goal
Menyediakan pengelolaan user, membership, role, dan akses per sekolah.

### Core Roles
Minimal:
- platform_admin
- school_admin
- editor

Jangan menambah role tanpa kebutuhan nyata.

### Features
- Invite user
- Join school
- Remove member
- Change role
- Reset/revoke session bila diperlukan

### Authorization
Permission minimal:
- manage_school
- manage_members
- manage_content
- manage_settings

### Rules
- platform_admin bukan bagian dari tenant biasa
- school_admin hanya mengelola school miliknya
- editor tidak boleh mengelola billing atau member jika tidak diberi hak

### Acceptance Criteria
- Access control konsisten
- Role tidak hardcoded tersebar di banyak file
- Unauthorized mutation ditolak server-side
