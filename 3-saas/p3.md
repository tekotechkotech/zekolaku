# PRD 3 — SaaS
## Phase 3: SaaS Management & Plans

### Goal
Membuat platform memiliki konsep plan dan administrasi tenant.

### Core Entities
- plans
- subscriptions
- subscription_events optional
- feature_limits

### Example Limits
- max_members
- max_news
- max_media_storage
- custom_domain_enabled
- premium_theme_enabled

### Platform Admin
Features:
- List schools
- View school status
- Activate/deactivate school
- Assign/change plan
- View usage summary

### Subscription Status
Minimal:
- trial
- active
- past_due
- suspended
- cancelled

### Important
Belum wajib terhubung payment gateway.

### Acceptance Criteria
- Setiap school memiliki plan
- Feature limit dapat dicek server-side
- Platform admin dapat mengelola tenant tanpa masuk sebagai user tenant
