# PRD 3 — SaaS
## Phase 5: Billing, Limits & Platform Infrastructure

### Goal
Menambahkan fondasi monetisasi dan operasional SaaS.

### Billing
- Payment provider abstraction
- Subscription lifecycle
- Payment history
- Invoice reference
- Grace period

### Usage
Track minimal:
- members
- content count
- media storage
- enabled premium features

### Notifications
- Trial ending
- Payment due
- Subscription suspended
- Invite member

### Infrastructure
- Structured logging
- Error monitoring
- Background jobs bila memang diperlukan
- Rate limiting
- Health check

### Rules
- Semua limit divalidasi server-side
- Billing logic tidak ditaruh di UI
- Jangan blokir akses data user secara destruktif saat plan turun

### Acceptance Criteria
- Subscription state memengaruhi feature access
- Limit usage bekerja
- Event penting tercatat
- Sistem siap diintegrasikan payment gateway production
