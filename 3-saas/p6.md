# PRD 3 — SaaS
## Phase 6: Production Hardening

### Goal
Membuat SaaS siap dipakai production oleh banyak sekolah.

### Security
- Tenant isolation test
- Authorization test
- Session security
- Rate limit
- Upload security
- Secret management
- Dependency audit

### Reliability
- Automated backup database
- Backup media
- Restore procedure
- Health monitoring
- Error monitoring
- Database migration strategy

### Performance
- Query review
- Indexing
- Pagination
- Image optimization
- CDN/object storage migration bila diperlukan
- Caching hanya jika ada kebutuhan nyata

### Domain
- Custom domain support
- Domain verification
- SSL strategy

### Developer Experience
- Environment documentation
- Deployment documentation
- Migration documentation
- Seed/demo tenant
- Basic test coverage

### Acceptance Criteria
- Tenant isolation telah diuji
- Backup dan restore terdokumentasi
- Deployment repeatable
- Monitoring aktif
- SaaS siap onboarding sekolah baru tanpa perubahan kode manual
