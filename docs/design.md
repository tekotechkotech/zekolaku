# Design

## Direction

Modern, clean, professional, and welcoming. The design should feel appropriate for an educational institution without becoming visually heavy.

## Layout

- Clear navigation
- Strong hero section
- Short information blocks
- Consistent section spacing
- Clear calls to action
- Responsive layout

## Visual Priorities

1. Readability
2. School identity
3. Clear information hierarchy
4. Accessibility
5. Visual polish

## Components

Potential reusable components include:

- Navbar
- Hero
- Section heading
- Profile highlight
- Program card
- Facility card
- News card
- Gallery item
- CTA
- Footer

Do not create a component merely to avoid a few repeated lines. Reuse should improve clarity or consistency.

## Content

Use realistic placeholder content during development, but keep it clearly replaceable with the school's actual information.
